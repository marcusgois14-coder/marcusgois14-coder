# Dados de demonstração

O banco foi criado com 64 pedidos de exemplo (`orders.source = 'demo'`) espalhados pelas 13 lojas nos últimos 30 dias, para o painel, os relatórios e a lista de clientes já mostrarem números. Os clientes de exemplo usam telefones com DDD 00 (inexistente), então não coincidem com ninguém real.

Antes de começar a vender, rode `limpar_demonstracao.sql` no SQL Editor do Supabase.
